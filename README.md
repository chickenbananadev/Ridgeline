# Ridgeline

CRM for Supreme Building Group — commission structures (role-gated), Code Verify, and Insurance Resources.

## Modules

- **Financials** — Admin-only commission structure selector: Net Profit (default), Gross Profit, 10/50/50, Gross Contract. Sales reps see payout only, not the levers or company splits.
- **Code Verify** — Zip lookup for adopted building code, permit rules, and inspector info, with links to official sources (codes.ohio.gov, KY DHBC, ICC Digital Codes, Municode) and a verification status badge per jurisdiction.
- **Insurance Resources** — Ohio Insurance Law, Policy Provisions, Documentation Checklist, Claim Tips, Do & Don't, Truck Cheat Sheet.

## Files

- `ridgeline-update.jsx` — this module, a single React component (default export). Merges into the master Ridgeline app file.
